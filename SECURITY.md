# Security Policy

## Reporting a vulnerability in this project's code

Please use [GitHub Security Advisories](../../security/advisories/new) to
report it privately rather than opening a public issue. Include what you
found, how to reproduce it, and its impact if you can.

There's no formal SLA, but reports are taken seriously and a fix or
mitigation is the priority once something is confirmed.

## Reporting a vulnerability in a specific hosted instance

This is self-hosted software — if you've found something wrong with a
particular running instance (not the software itself), that's a different
report than the one above. Each instance can publish its own security
contact at `/.well-known/security.txt` ([RFC 9116](https://www.rfc-editor.org/rfc/rfc9116)); check there first.

## Supported versions

There's no versioned release track yet — `master` is the supported branch.
